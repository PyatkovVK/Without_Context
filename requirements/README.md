# Without Context requirements

This folder contains the product requirements for the MVP. All requirement documents, directory names and filenames are in English.

Each file describes one element: its purpose, behavior, constraints and acceptance criteria. Update the relevant document in the same task when behavior changes. Record new requests with the status "Planned"; use "Implemented" only for behavior available in the application. Technical development rules are defined in AGENTS.md and ARCHITECTURE.md.

Use fictional examples only. Do not include real documents, keys, personal data, paths to user folders or exported chats in requirements.
